HTML PAGE FORMAT

  • ! - Boiler plate
  • Comments : < !--(contents) -- >
  • Main tag : < html> < / html >

TWO PARTS : Head , Body

  1. HEAD : < title>< /title> - Name of the webpage
  2. BODY :
    1. Header : < header > < /header>

    2. Main : < main > < /main> -
      • article - < article > < /article>
      • section - < section > < /section>

    3. Footer : < footer > < /footer>

BASIC TAGS

  1. Single Tag - < tagname/>
  2. Double Tag - < tagname> < /tagname>

TAGS DESCRIPTION
< h1>< /h1> to < h6> < /h6> Headings tag
< p> < /p> Paragraph tag
< b> < /b> Bold tag
< i> < /i> Italic tag

LINKS

DOUBLE TAG - < a href = "link" > text to represent link < /a>

Links can be three types-

  • External links - direct link
  • Internal file from same directory of current - direct link
  • Internal file from diff directory - dirname/filename

By default,when links are clicked,they open in same web page.To change this and allow opening in new tab- target="_blank"

When link is opened for first time - blue, already opened/clicked - purple

IMAGES

Single tag - < img src="image link" alt="text if image fail to open" / >

  • src- link of the image
  • alt- the text displayed if image failed to display else not displayed
  • height,width- resize the image

VIDEOS

INTERNAL VIDEOS

Double tag - < video src="video link" controls >text < /video>

  • src- link of the video
  • text- the text displayed if video failed to display else not displayed
  • height,width- resize the video
  • controls- if not used,the video cannot be displayed else is like image
  • poster- link of the image for thumbnail
  • autoplay- autoplays video
  • loop- loops video
